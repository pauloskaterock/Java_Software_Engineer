## Como Executar os Projetos

### Compilar

```bash
javac NomeDoArquivo.java
```

### Executar

```bash
java NomeDoArquivo
```

### Projetos Maven

```bash
mvn clean install
mvn test
```

### Projetos Gradle

```bash
gradle build
gradle test
```
